# AI Event Recommendation System

An intelligent, full-stack, production-grade **AI Event Recommendation System** built for college campuses and academic communities. The system combines modern reactive frontend design, a robust Node.js/Express REST backend, MongoDB Atlas cloud storage, and a scikit-learn machine learning recommendation microservice.

---

## 1. Project Description

The **AI Event Recommendation System** enables students and faculty to discover, evaluate, and register for campus events based on their individual interests, location, budget, and preferred event categories. Administrators manage events and audit registrations in real time through an authenticated admin control dashboard.

The recommendation engine pairs user preferences with currently active events in MongoDB Atlas. If an exact category (e.g., *Workshop*) has active events, the system ranks and recommends them. If an exact category is currently unavailable, it notifies the user and surfaces relevant active events from related categories (e.g., *Tech Talk*, *Hackathon*, *Coding Contest*) without modifying or falsifying event attributes.

---

## 2. Features

* **AI-Powered Recommendation Microservice**: Scikit-Learn Logistic Regression pipeline featuring `ColumnTransformer`, `OneHotEncoder`, and `StandardScaler` to compute accurate match scores.
* **Intelligent Fallback Category Taxonomy**: Enforces Section 14 category fallback logic (exact matching when available, polite fallback to related active categories when unavailable).
* **Live MongoDB Atlas Integration**: True cloud database synchronization for users, events, and bookings. Never invents synthetic live events.
* **Strict Registration Deadline Enforcement**: Automated backend time checks ensure no registrations are accepted after deadlines have passed. Expired events are automatically excluded from recommendation candidate pools.
* **Atomic Seat Management**: Atomic seat decrementing avoids race conditions and eliminates overselling. Shows "Sold Out" once capacity reaches zero.
* **Duplicate Booking Prevention**: Unique compound database indexes block duplicate registrations for the same user and event.
* **Role-Based Authentication & Authorization**: Salted bcrypt password hashing and JWT authentication for users and administrators.
* **Full Administrator Dashboard**: Comprehensive CRUD interface for managing events, reviewing registration logs, and tracking system-wide attendance.
* **Modern Responsive Interface**: Custom electric-blue and dark-navy aesthetic with glassmorphism, responsive across desktop, tablet, and mobile devices.
* **512 MB RAM Deployment Ready**: Ultra-lightweight ML architecture specifically optimized for low-memory Render deployments.

## 5. MongoDB Atlas Setup

1. Create a free account at [MongoDB Atlas](https://www.mongodb.com/atlas).
2. Create a new cluster (e.g., M0 Free Shared Tier).
3. Under **Database Access**, create a database user with Read/Write privileges. Note the username and password.
4. Under **Network Access**, add IP Address `0.0.0.0/0` (Allow Access from Anywhere) or add your current IP address.
5. In the cluster view, click **Connect** -> **Drivers** -> **Node.js**.
6. Copy your connection string. It will look like:
   ```text
   mongodb+srv://<username>:<password>@cluster0.mongodb.net/event_recommendation_db?retryWrites=true&w=majority
   ```
7. Substitute `<username>` and `<password>` with your database credentials.

## 6. Dataset Placement Instructions

The machine learning model relies on an external training dataset.

1. Do not rename the dataset columns. The file must contain exactly these six columns:
   ```text
   user_interest,location,budget,event_category,event_price,event_popularity
   ```
2. Place the CSV file into the following directory:
   ```text
   ml_service/data/event_recommendation_20000.csv
   ```
3. If any of the required columns are missing, `train_model.py` will report a descriptive error specifying the exact missing column names.

## 7. Model Training Instructions

Once your dataset has been copied to `ml_service/data/event_recommendation_20000.csv`:

```bash
# Navigate to the ML directory
cd ml_service

# Create virtual environment
python -m venv .venv

# Activate virtual environment
# On Windows:
.venv\Scripts\activate
# On macOS / Linux:
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the training script
python train_model.py
```

The script will:
1. Verify dataset existence and validate all 6 columns.
2. Formulate balanced positive/negative feature samples.
3. Fit the `ColumnTransformer` + `LogisticRegression` pipeline.
4. Output accuracy, ROC-AUC, and precision/recall metrics.
5. Save the trained pipeline to `ml_service/model/recommendation_model.joblib`.

## 10. API Documentation

### Authentication Endpoints
* `POST /api/auth/register` — Register new user account.
  * Body: `{ name, email, password, confirmPassword }`
* `POST /api/auth/login` — Authenticate user and return JWT.
  * Body: `{ email, password }`
  * Returns: `{ token, user: { id, name, email, role } }`
* `GET /api/auth/me` — Return current logged-in user profile (Bearer token required).

### Event Endpoints
* `GET /api/events` — Retrieve all active events (`deadline > now` and `seats > 0`). Supports query filters `?category=&location=&search=`.
* `GET /api/events/:id` — Retrieve full event details by ID.
* `GET /api/admin/events` — (Admin only) Retrieve all events including expired and full events with booking metrics.
* `POST /api/admin/events` — (Admin only) Create a new event.
* `PUT /api/admin/events/:id` — (Admin only) Update an existing event.
* `DELETE /api/admin/events/:id` — (Admin only) Delete an event and related registrations.

### Recommendation Endpoints
* `POST /api/recommendations` — Fetch AI-ranked recommendations for active MongoDB events.
  * Body:
    ```json
    {
      "user_interest": "Technology",
      "location": "Chennai",
      "budget": 1000,
      "event_category": "Workshop"
    }
    ```
  * Response:
    ```json
    {
      "exact_match": true,
      "message": "Found 1 Workshop event(s) matching your profile.",
      "requested_category": "Workshop",
      "recommendations": [ ... ]
    }
    ```

### Registration Endpoints
* `POST /api/registrations` — (Authenticated) Book a seat for an event.
  * Body: `{ eventId, name, email, phone }`
* `GET /api/my-registrations` — (Authenticated) Fetch events booked by the current user.
* `GET /api/admin/registrations` — (Admin only) Audit all registrations across all events.

## 11. Render Deployment Instructions

The application is structured for deployment on Render's free or starter tiers (512 MB RAM limit).

### 1. ML Service (Render Web Service)
* **Environment**: Python 3
* **Root Directory**: `ml_service`
* **Build Command**: `pip install -r requirements.txt && python train_model.py` (ensure dataset is committed or downloaded from secure storage)
* **Start Command**: `gunicorn -w 1 -b 0.0.0.0:$PORT app:app` (or `python app.py`)
* **Environment Variables**:
  * `PYTHON_VERSION`: `3.10.12`
  * `PORT`: `10000`

### 2. Backend Service (Render Web Service)
* **Environment**: Node.js
* **Root Directory**: `backend`
* **Build Command**: `npm install`
* **Start Command**: `npm start`
* **Environment Variables**:
  * `MONGODB_URI`: `<Your MongoDB Atlas Connection String>`
  * `JWT_SECRET`: `<Production Secret>`
  * `ML_SERVICE_URL`: `<URL of your deployed ML Service>`
  * `PORT`: `5000`

### 3. Frontend Service (Render Static Site)
* **Root Directory**: `frontend`
* **Build Command**: `npm install && npm run build`
* **Publish Directory**: `dist`
* **Environment Variables**:
  * `VITE_API_URL`: `<URL of your deployed Backend Service>/api`

## 12. Troubleshooting Guide

| Issue | Cause | Solution |
| :--- | :--- | :--- |
| `MongoDB Atlas connection error` | Network whitelist or invalid credentials | Verify username/password in `backend/.env`. Ensure `0.0.0.0/0` is added to Atlas IP Access List. |
| `Dataset missing required columns` | CSV header mismatch | Ensure CSV columns are exactly: `user_interest,location,budget,event_category,event_price,event_popularity`. |
| `ML Service fallback mode active` | `recommendation_model.joblib` not found | Place CSV in `ml_service/data/` and run `python train_model.py`. The service will automatically load the model once generated. |
| `Registration deadline has passed` | Event timestamp expired | As per Section 20, deadlines are strictly enforced by the backend. Use the Admin Dashboard to extend the event deadline. |
| `Event is full` | Zero remaining seats | The event capacity has been reached. Increase available seats via the Admin Dashboard. |
